Zilli

企业级 AI Agent 自主开发、隐私治理与强化学习训练框架

概述

Zilli 是一个面向 AI 自主开发和企业隐私治理的下一代 Agent 工具工程方案。 核心理念是"AI 写 AI"、"评估即开发"、"从环境中来"以及"从 Agent 到 RL"。 系统将五阶段 RL 训练流水线（形成自我进化闭环）与企业级数据分类（5 级）、 本地-云端混合执行、隐私门控和合规报告（GDPR/HIPAA/SOC2）融为一体。

五阶段架构

Phase 1: 定义

定义可自动验证的任务集，设计基于 Pydantic 的类型安全 Agent API 契约。

Phase 2: 数据

搭建模拟沙箱环境，生成轨迹数据，建立分层经验回放池（黄金轨迹 + 失败反思）。

Phase 3: 基础设施

部署 SGLang + Megatron-LM 异构算力，实现长度自适应控制和异步 Rollout 调度。

Phase 4: 训练

CISPO 算法确保多轮 Agent 训练稳定性，支持 RLVR 奖励塑形和 GRPO 基线。

Phase 5: 进化

离线进化引擎（DSPy + GEPA）优化 Skill，从生产数据持续学习。

企业隐私

Zilli 的隐私模块为敏感的企业工作负载提供端到端数据治理。 五级数据分类（PUBLIC / INTERNAL / CONFIDENTIAL / RESTRICTED / REGULATED） 驱动整个 Agent 生命周期中的自动化策略执行。

DataClassifier

5 级数据分类器，自动检测 PII/PHI。 任何包含个人标识符的数据自动提升至 CONFIDENTIAL 级别以上。

PolicyStore

租户级隐私策略持久化存储（JSONL 格式）。 支持按数据分类级别的允许/拒绝规则、 集成点和保留期配置。

ReIDAssessor

去标识数据集的重识别风险评估。 评估 singleton、k-anonymity 和 linkage 风险， 标记任何残留重识别概率超过 5% 的情况。

ConsentManager

数据点级别的精细同意管理。 支持撤回、过期和基于目的的同意查询。 完整的同意生命周期事件审计追踪。

PrivacyEngine

协调引擎，整合分类器、策略、同意和重识别评估 为统一决策流水线。对外暴露单一 evaluate() 入口点。

混合执行

Zilli 的混合执行层以隐私保护方式桥接本地和云端模型部署。 敏感数据留在本地；经脱敏的载荷可在适当时使用云端模型。

PrivacyGatekeeper

根据数据分类和租户策略做出本地/云端/拒绝决策。 RESTRICTED 和 REGULATED 数据强制本地执行； CONFIDENTIAL 数据经脱敏后可路由至云端。

Sanitizer

在云端分发前从数据载荷中脱敏 PII/PHI。 按数据类型使用配置的脱敏策略： 掩码、哈希、替换或移除。

HybridExecutor

执行模型推理，自动优先本地路由。 仅当本地模型不可用且数据已成功脱敏时 才回退到云端。

合规与治理

Zilli 基于现有审计追踪（JSONL 格式）为监管框架生成合规报告。 无需额外存储基础设施。

GDPR

被遗忘权审计、同意记录、数据处理活动日志、 跨境传输文档。

HIPAA

PHI 访问日志、最低必要使用验证、 泄露通知就绪评估。

SOC2

安全监控证据、访问控制日志、 变更管理记录、风险评估摘要。
