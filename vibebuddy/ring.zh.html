Vibe Ring

AI 智能戒指 — 批准、拒绝、交互，快如思维

两款型号

Vibe Ring 通过 BLE 连接 Claude Desktop，用手势即可批准或拒绝 AI 操作。两款可选：极简款专注手势控制与超长续航，OLED 旗舰款提供可视化反馈和自定义角色包。

Vibe Ring

纯手势控制，超低功耗
  • 主控: nRF54L15 (Cortex-M33 @ 128MHz)
  • 连接: BLE 5.0+ NUS 协议
  • 传感器: BMI270 6 轴 IMU
  • 反馈: 线性马达 + RGB LED (WS2812B)
  • 电池: 19-21mAh，7-10 天续航
  • 充电: NFC 无线充电
  • 材质: 钛合金 / 陶瓷
  • 重量: <6g
  • 防水: IP68 / 5ATM
  • 宽度: 8-10mm
定位: 极简设计，稳定连接，长续航

Vibe Ring Pro

OLED 显示屏 + 触摸 + 手势
  • 主控: nRF54L15 + RISC-V 协处理器
  • 屏幕: 柔性 OLED 160×32 (270°环绕)
  • 触摸: 屏幕表面电容触控
  • 传感器: BMI270 6 轴 IMU
  • 反馈: 线性马达 + RGB LED
  • 电池: 24-25mAh，5-7 天续航
  • 充电: NFC 无线充电
  • 材质: 钛合金 / 陶瓷
  • 重量: ~6.6g
  • 自定义: GIF 角色包
定位: 丰富视觉反馈，自定义角色，全方位交互

核心交互

手势控制

双击批准、长按拒绝、转腕忽略。无需屏幕即可完成。

BLE 协议

Nordic UART 服务 + JSON 数据包，完全兼容 Claude Desktop 权限系统。

震动反馈

请求、批准、拒绝、报警各有不同的震动模式，指尖即可感知。

工作流程

1. 权限请求

Claude Desktop 通过 BLE 发送 JSON 权限请求。戒指短-短-长震动，LED 黄色闪烁。

2. 手势回应

双击批准 — 绿色 LED + 短震一下。长按拒绝 — 红色 LED + 两下短震。

3. 实时状态

Pro 款 OLED 显示 Claude 状态：睡眠、待机、忙碌、等待、庆祝、眩晕——各有独立动画。

4. 自定义角色

Pro 用户可通过 Claude Desktop 上传自定义 GIF 角色包。拖拽、佩戴——AI 就在指尖。

技术参数

通信

  • BLE 5.0+ NUS 服务
  • JSON 数据协议
  • 30-50ms 连接间隔
  • 从机延迟启用

电源管理

  • 深度睡眠 <5µA
  • RTC 定时唤醒
  • IMU 中断唤醒
  • NFC 无线充电 (~45%效率)

手势识别

  • IMU 25Hz 采样
  • 阈值检测算法
  • 可升级 TFLite Micro
  • 防误触优化

耐用性

  • 钛合金/陶瓷外壳
  • 柔性电路板 (FPC)
  • IP68 / 5ATM 防水
  • 全封闭无按键
